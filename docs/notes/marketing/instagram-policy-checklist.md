# Instagram 연동 정책 체크리스트 (마케팅)

> 작성: 재헌(마케팅) · 2026-10-26 · 상태: **초안, 변호사·원문 확인 전**
> 읽은 자료: Meta 플랫폼 약관, 개발자 정책(한국어 번역본), Instagram 이용약관, 커뮤니티 규정(스팸·진짜 신원·가짜 행위·금지된 상업 행위), 콘텐츠 게시 API 문서. 일부는 요약을 거쳐 읽었으므로 게시 전에 원문과 대조한다.
> 이 문서의 결정은 재헌(2026-10-26)이 정했고, 위반 시 게시하지 않는다.

## 1. 결정

1. **쿠폰은 공개 쿠폰 형태**로 한다(일본 기업들이 SNS에 올리는 방식). 누구나 볼 수 있고 참여 조건이 없다. **좋아요·팔로우·공유·댓글을 조건으로 걸지 않는다.**
2. **제약 사항을 반드시 게시물에 공개한다.** 제약 사항이 없는 쿠폰 계획은 평가 단계에서 reject한다.
3. **AI 라벨은 무조건 넣는다.** 사진이 AI가 아니어도 글을 AI가 쓰므로 예외를 두지 않는다. 계정 라벨, 게시물 API 자기공개, 캡션 안내문, 영상 안 안내문을 모두 넣는다.
4. **상업 행위(주문·결제·환불·교환 등)는 이용약관에 따른다**고 게시물·프로필에 표시한다.

## 2. 쿠폰 게시물 필수 항목 (제안, 코드는 설정에서 관리)

- 제약 사항: 사용 기간, 대상, 최소 주문 금액과 할인 상한, 1인당 사용 횟수, 예산·수량 소진 시 종료, 다른 쿠폰과 중복 사용 여부, 환불 시 쿠폰 처리
- **캣북스는 시연용 가상 서비스이고 실제 거래·배송이 없다**는 문구(실제 혜택으로 오해하지 않게)
- AI 생성 안내문
- 이용약관 안내: "주문·결제·환불 등은 캣북스 이용약관·구매자 이용약관에 따릅니다" + 약관 링크

## 3. 근거와 주의점

| 항목 | 근거 | 대응 |
|---|---|---|
| 참여 조건부 쿠폰 금지 | 커뮤니티 규정 스팸: 참여의 대가로 금전적 가치가 있는 것을 제공, 좋아요·공유 게이팅 금지 | 공개 쿠폰, 참여 조건 없음 |
| 빈도·반복 | 스팸: 매우 높은 빈도, 반복 게시 | 일일 게시 건수 상한, 문구 변주 |
| 링크 | 스팸: 오해를 부르는 링크 금지 | 쿠폰 링크는 정확한 도착지로 |
| 가격·환불 | 금지된 상업 행위: 광고와 다른 상품·약속한 환불 정책 미이행 | 게시 문구를 푸터 환불 기준과 맞춤 |
| 신원 | 이용약관 4.2, 진짜 신원 표시: 사칭·신원 허위 표시 금지 | 계정 등록 정보는 실제 운영 주체, 소개글에 AI 생성 명시 |
| AI 자기공개 | 게시 API `is_ai_generated=true`(캐러셀은 컨테이너에만) | 모든 게시물에 켠다 |
| 개인정보처리방침 | 플랫폼 약관 4.a·4.b: 공개 URL과 삭제 요청 방법 | 방침 공개 URL, 권리행사 창구 마련(현재 `[확인 필요]`) |
| 토큰 | 플랫폼 약관 6.a.iv | `.env`에만, 코드·로그·이슈에 쓰지 않음 |

## 4. 하지 않는 것

- 좋아요·팔로워·계정 거래, 허위 행동 유도(개발자 정책 §2.7, §5.6.2b)
- 자동 DM 발송(개발자 정책 §5.2, 동의·수신 거부 조건)
- 스토리 게시(개발자 정책 §2.6a의 "워터마크·홍보 콘텐츠" 문구와 AI 안내 오버레이가 충돌하는지 확인될 때까지). 피드·릴스부터 한다.
- 댓글·DM 수집(개인정보 범위 확대)

## 5. 확인할 것 (변호사·Meta 원문)

- 개발자 정책 §6.2: "사전 승인 없이 게시만을 위한 용도로 Instagram 플랫폼을 사용하지 말 것"이 우리(자사 계정에 자사 콘텐츠 게시)에도 적용되는지
- 브랜디드 콘텐츠 정책: 쿠폰 캠페인이 해당하는지(협찬·광고 성격이면 도구 사용 의무)
- 계정 단위 "AI-generated profile" 라벨의 공식 설정 방법
- 인공지능기본법 제31조 의무 주체, 표시광고법 심사지침, 과기정통부 투명성 가이드라인의 표시 방식
- 게시 한도(24시간 100건 / 50건 어긋남), 개발 모드·테스트 사용자 요건
- 구매자 이용약관(아직 없음)이 나와야 "이용약관에 따른다" 표시의 링크 대상이 완성된다
